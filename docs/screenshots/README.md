# 截图文件说明

请将以下截图文件放在本目录中：

## 需要准备的文件

| 文件名 | 说明 |
|--------|------|
| `login.png` | 登录页面 |
| `announcements.png` | 通知公告管理页 |
| `dashboard.png` | 数据统计仪表盘 |
| `books.png` | 图书管理页面 |
| `categories.png` | 分类管理页面 |
| `borrows.png` | 借阅管理页面 |
| `fines.png` | 罚款管理页面 |
| `readers.png` | 读者管理页面 |
| `logs.png` | 操作日志页面 |
| `settings.png` | 系统设置页面 |
| `dashboard-dark.png` | 深色模式仪表盘 |
| `books-dark.png` | 深色模式图书管理 |
| `mobile-sidebar.png` | 移动端侧边栏展开效果 |
| `mobile-table.png` | 移动端表格适配效果 |

## 截图建议

- 建议截图宽度为 1280~1440px
- 移动端截图建议宽度为 375~414px（iPhone 尺寸）
- 可使用浏览器开发者工具的截图功能或第三方工具（如 Snipaste）
