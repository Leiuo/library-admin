# Vue 3 图书馆后台管理系统

一个基于 Vue 3 + Element Plus 构建的现代化图书馆后台管理系统，提供图书管理、借阅管理、读者管理和数据统计等功能。

## 功能特性

### 图书管理

- 图书列表展示与搜索
- 图书信息的新增、编辑、删除
- 图书状态管理（可借/借出）

### 借阅管理

- 借阅记录列表展示（支持分页）
- 图书借出与归还操作
- 借阅日期校验（应还日期 ≥ 借书日期）
- 逾期借阅高亮标记

### 读者管理

- 读者信息管理（新增、编辑、删除）
- 批量导入（CSV/JSON）与批量删除
- 读者借阅历史页面（含统计卡片）

### 数据统计

- 馆藏总量、借出数量统计
- 图书状态分布饼图
- 月度借阅趋势折线图
- 热门图书 TOP5 排行
- 读者借阅排行 TOP5

## 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue | 3.5+ | 渐进式 JavaScript 框架 |
| Vite | 8.0+ | 下一代前端构建工具 |
| Element Plus | 2.13+ | Vue 3 组件库 |
| Pinia | 3.0+ | Vue 状态管理库 |
| Vue Router | 5.0+ | Vue 路由管理器 |
| ECharts | 6.0+ | 数据可视化图表库 |

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式运行

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

- **用户名**: 任意用户名

## 使用说明

1. **登录系统**: 打开浏览器访问 `http://localhost:5173`，输入用户名和密码登录
2. **导航菜单**: 左侧侧边栏提供系统功能导航，支持折叠展开
3. **数据统计**: 首页展示图书馆运营数据统计和可视化图表
4. **图书管理**: 在图书列表中进行新增、编辑、删除操作
5. **借阅管理**: 管理图书借出和归还，查看借阅历史
6. **读者管理**: 管理读者信息，维护读者档案
